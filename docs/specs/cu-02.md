# CU-02 — Lanzar evaluación

## Objetivo
Lanzar una evaluación versionada e invitar respondentes.

## Flujo
1. Elige ruta 15/27/38 y congela QuestionnaireVersion.
2. Genera invitaciones con enlace firmado (expira, un uso).
3. Envía correo o comparte WhatsApp `wa.me`.
4. Seguimiento de avance por respondente.

## Criterios de aceptación
- [ ] La evaluación congela la versión del cuestionario.
- [ ] Invitación firmada, con expiración y un solo uso.
- [ ] «No sé» se registra como hallazgo, no como nivel.
- [ ] Resultados no visibles al cliente hasta publicar.
