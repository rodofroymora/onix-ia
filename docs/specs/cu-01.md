# CU-01 — Alta de organización

## Objetivo
El consultor crea una organización cliente, aplica plantilla sectorial y define el mapa de responsables.

## Actores
consultant

## Flujo principal
1. Abre Organizaciones → Alta.
2. Captura nombre, sector (8 plantillas) y país (MX por defecto).
3. El sistema crea org, aplica plantilla (roles sugeridos, pesos base, acciones tipicas).
4. Edita mapa de responsables y guarda (bitácora).

## Criterios de aceptación
- [ ] Se puede crear org con sector de la lista de 8.
- [ ] Queda `organization_id` en mapa y memberships.
- [ ] Un `client_admin` de otra org no ve la nueva org (aislamiento).
- [ ] Queda registro en AuditLog.
